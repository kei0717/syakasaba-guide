# チャットコマンド

ふつうのチャットは **近くにいるプレイヤーにだけ** 見えます。次のコマンドをチャット欄に入力すると、いろいろな操作ができます。

::: tip
`/kei:a` のような正式な名前でも、`/a` のような短い名前でも動きます。昔の `!a` のような書き方も今のところ使えます。
:::

## 全体チャット {#全体チャット}

```
/a 送りたい文
/all 送りたい文
```

入力した文を、サーバー全体のチャットに流します。

::: warning
細かい会話に全体チャットを使うのは、なるべく避けてください。電話を持っていない序盤に仲間と合流するときや、緊急時の連絡用です。([参加規約](/guide/rules#個人の裁量で行っていただきたいこと))
:::

## 頭の上に文を出す {#text}

```
/text 表示したい文
/text reset
```

- `/text 表示したい文` … 頭の上に好きな文を表示します。
- `/text reset` … 頭の上の文を消します。

[K-phoneの「Text」アプリ](/play/kphone#text) でも同じことができます。

## 配信モード {#live}

```
/live on
/live off
```

配信モード(Liveモード)をオン・オフします。配信するときは必ずオンにしてください。([参加規約: 配信活動について](/guide/rules#配信活動について))

[K-phoneの「Live」アプリ](/play/kphone#live) でも切り替えられます。

## ログイン {#login}

```
/login パスワード
```

初めてサーバーに入ったときに、動けるようにします。

## ミュート {#mute}

```
/mute
/mute true
/mute false
```

- `/mute` … ミュートのオン・オフを切り替えます。
- `/mute true` … ミュートにします。
- `/mute false` … ミュートを解除します。

`/mute` の代わりに `/m` でも使えます(`/m`、`/m true`、`/m false`)。

## スキルツリーを開く {#skill}

```
/skill
```

[スキルツリー](/play/skilltree) の画面を開きます。

## 金魚すくいのランキング {#rank}

```
/rank
```

金魚すくいのスコアのランキングをチャットに表示します。

## ギフトコード {#giftcode}

```
/giftcode ギフトコード
```

支援Tシャツなどのギフトコードを入力すると、アイテムを受け取れます。

### 公開済みのギフトコード

| 入力するコード | もらえるもの |
| --- | --- |
| season1のログインパスワード | しゃかさばTシャツ -season1- |
| season2のログインパスワード | しゃかさばTシャツ -season2- |
| season3のログインパスワード | しゃかさばTシャツ -season3- |
| season2の支援コード | しゃかさば支援Tシャツ -season2- |
| season3の支援コード | しゃかさば支援リストバンド -season3- |
| season4の支援コード | しゃかさば支援タオル -season4- |
| `money`(ATMの貯金が金ブロック640個以上のとき) | レジブロックのレシピ本 |
