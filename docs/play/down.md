# ダウンと蘇生

体力が0になっても、すぐには死にません。その場に倒れ込む **ダウン** 状態になり、60秒のあいだに仲間が起こしてくれれば生き返ります。

<Shots :images="['down.webp']" alt="ダウン中の画面" />

## ダウンすると {#down}

- その場にへたり込み、ほとんど動けなくなります。ジャンプ・しゃがみ・アイテムの使用・ブロックやエンティティの操作はできません。
- 視点は自動で三人称になり、カメラは自由に回せます。
- 画面の上に **残り時間** が出ます。60秒たつと、そのまま力尽きて死にます。
- ダウン中は、ゾンビなどからの攻撃を受けても体力は減りません。
- 通話中の電話や、使っていたカメラ・フォーム・フックショットは切れ、乗り物からも降ろされます。
- ダウンした瞬間に、チャットには本来のデスログ(「○○はゾンビに殺された」など)が流れます。力尽きたときは「○○はダウンしたまま力尽きてしまった」と出ます。

::: tip 死ぬときとの違い
不死のトーテムを持っているときは、ダウンせずにトーテムが発動します。クリエイティブモードや `/kill` では、ダウンせずにそのまま死にます。
:::

## 仲間を起こす {#revive}

- ダウンした人のすぐ近く(2ブロック以内)で **しゃがみ続ける** と、3秒で起こせます。画面に進み具合が出ます。
- 途中でしゃがむのをやめたり離れたりすると、進み具合は少しずつ戻ります。
- 起きた人は体力が半分のハート1個、満腹度0の状態で立ち上がります。すぐに食べ物を渡してあげてください。
- 起こせるのは、自分がダウンしていない人だけです。

## 残り時間が早く減るとき {#faster}

| 状況 | 減り方 |
| --- | --- |
| 普段 | 1秒に1秒 |
| マグマ・火・奈落・水中(溺れ)・サボテン・凍えなど、環境のダメージを受けている間 | 1秒に8秒 |
| スペース(ジャンプ)を押す | 押すたびに8秒 |

助けが来そうにないときは、スペースを何度か押せば自分で諦められます。

::: warning ログアウトしても逃げられません
ダウン中にサーバーから抜けても、入り直すと残り時間の続きからダウンが始まります。
:::
