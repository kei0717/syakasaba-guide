# Discord botで追加できるもの

Discordのbot用チャンネルでコマンドを使うと、自分で描いた画像からオリジナルのアイテムやブロックを追加できます。追加したものは、ゲーム内のブロックで **パスワードを入力すると受け取れます**。

## 追加の流れ

1. Discordのbot用チャンネルで、下のコマンドに画像・名前・パスワードを付けて実行します。
2. サーバーの次回の再起動で、ゲームに反映されます(再起動は4時間ごと。[時刻はこちら](/guide/faq#再起動))。
3. ゲーム内で、種類に合ったブロックを使い、決めたパスワードを入力して受け取ります。

| 追加したもの | 受け取るブロック | 費用 |
| --- | --- | --- |
| アイテム・食べ物・飲み物・ブロック | ![](/game/textures/icon/add_alchemy.png){.hicon} 錬金ブロック | 1個ごとに金インゴット(下の表) |
| 服・帽子などのオシャレ装備 | ![](/game/textures/icon/add_tailoring.png){.hicon} 裁断ブロック | 金インゴット 10個 |
| ネザライトのツールの見た目 | ![](/game/textures/icon/add_smithing.png){.hicon} 鍛冶ブロック | 金インゴット 32個 |

錬金・裁断・鍛冶ブロックのレシピ本は、[スキルツリー](/play/skilltree) で手に入ります。

::: warning 初めて受け取るときは +10 金インゴット
アイテム・食べ物・飲み物・ブロック・服・ツールの見た目は、追加した種類を **ゲーム内で最初に受け取るときだけ**、上の費用に加えて **金インゴット10個** がかかります(2回目以降は通常の値段です)。種類が増えすぎてゲームのデータが重くならないようにするためです。
:::

::: warning パスワードについて
パスワードは、受け取るときと編集するときに使います。ほかの人と同じパスワードは使えません。知っている人なら誰でも受け取れるので、配りたい相手にだけ教えてください。
:::

::: info 追加したもののデザインについて
追加したブロックやアイテムのデザイン(スキンを除く)は、けい(主催者)が主催するイベントや制作物、コンテンツなどで、事前のお声がけなく使わせていただく場合があります。あらかじめご了承ください。→ [規約](/guide/rules#bot_design)
:::

## 画像のルール

- 形式は **PNG** だけです。
- アイコンやブロックの画像は **16×16 / 32×32 / 64×64** のどれかの正方形です。
- 服を着たときの画像(テクスチャ)とスキンは **64×64** か **128×128** です。128×128 にすると、同じ大きさのまま細かく描けます。
- アイテム・ツール・服のアイコンの画像は、色の付いた(透けていない)ピクセルが **全体の 1/8 以上** 必要です(16×16 なら 32 ピクセル以上)。ほとんど透明な画像は登録できません。
- 看板の画像には **透明・半透明** は使えません(くり抜かれた所から看板の内側が見えてしまうため)。パネルは完全な透明だけ使えます(その部分がくり抜かれます)。半透明が使えるのはフルブロックだけです。
- 2Dエディター・3Dエディターの **「提出前チェック」** を押すと、Discord bot に出せる画像かどうかを確かめられます。

## 画像を描けるサイト {#tools}

追加用の画像は、ブラウザで使える専用のエディターで描けます。描いた画像はPNGで保存して、そのままコマンドに付けられます。

<a class="ss-tool" href="../editor2d/" target="_blank">
  <b>2Dエディター</b>
  <span>アイテムのアイコンや、ブロックの面の画像を描けます。</span>
  <small>アイテム 16×16 / 32×32、ブロック 16×16 / 32×32 / 64×64</small>
</a>

<a class="ss-tool" href="../editor3d/" target="_blank">
  <b>3Dエディター</b>
  <span>服の着たときの画像を、3Dで着せた見た目を確かめながら描けます。</span>
  <small>64×64 / 128×128(帽子・服・ズボン・靴)</small>
</a>

</div>

どちらのエディターにも、**塗りつぶし**・**左右対称**(オンにすると反対側にも同じように描かれる)・**提出前チェック** があります。3Dエディターでは、モデルにカーソルを乗せると平面の画像の同じマスが光り(逆も同じ)、プレイヤーに着せた状態で歩かせて確かめることもできます。

::: info 半透明はエディターでは描けません
ブロックは半透明の画像にも対応していますが、エディターは操作をかんたんにするため、半透明の色は使えません(完全な透明は使えます)。半透明のブロックを作りたいときは、ほかのお絵かきソフトで描いた画像を使ってください。
:::

## アイテムを追加する `/add_item` {#add_item}

| 項目 | 内容 |
| --- | --- |
| `type` | 種類: 普通のアイテム / 食べ物 / 飲み物 |
| `image` | アイコン画像 |
| `name` | アイテムの名前 |
| `password` | 受け取り用のパスワード |
| `max_stack` | (任意)最大スタック数。初期値64 |
| `nutrition` | (任意・食べ物/飲み物)満腹度の回復量 1〜20。初期値1 |
| `drink_color` | (任意・飲み物)コースターに置いたときの色。初期値は水の色 |
| `drink_glass` | (任意・飲み物)コースターに置いたときのグラスの種類。初期値は普通のグラス |

**錬金ブロックでの値段(1個あたり)**

- 普通のアイテム: 金インゴット 0.5個
- 食べ物・飲み物: 金インゴット 0.5個 + 満腹度 × 0.25個

まとめて受け取るときは、合計を切り上げた数の金インゴットが必要です。

::: tip 飲み物とコースター
飲み物は、飲むモーションで食べられるアイテムになります。[コースター](/items/recipes#coaster) に置くと、追加したときに選んだ色とグラスで表示され、もう一度素手でクリックすると名前ごと戻ってきます。
:::

## ブロックを追加する `/add_block` {#add_block}

| 項目 | 内容 |
| --- | --- |
| `block_type` | 種類: パネル / 看板 / フルブロック |
| `texture` | ブロックの画像 |
| `name` | ブロックの名前 |
| `password` | 受け取り用のパスワード |
| `light_level` | (任意)明るさ 0〜15。初期値0(光らない) |
| `vv_glow` | (任意)バイブラントビジュアルで光らせる強さ 0〜15 |
| `rotate` | (任意・フルブロックのみ)置いた向きで上面の向きを変える |

- **パネル** … 壁・床・天井に貼れる薄い板です。画像が板の面いっぱいに貼られます。透明な所はくり抜かれます(半透明は使えません)。
- **看板** … 看板の面に画像が表示されます。透明・半透明は使えません(すべて不透明な画像にしてください)。
- **フルブロック** … 全部の面が同じ画像の1マスのブロックです。透明・半透明の画像にも自動で対応します(半透明は [エディター](#tools) では描けません)。

錬金ブロックでの値段は、1個あたり金インゴット0.5個です。

## オシャレ装備を追加する `/add_clothing` {#add_clothing}

| 項目 | 内容 |
| --- | --- |
| `clothing_type` | 部位: 帽子 / 服 / ズボン / 靴 |
| `icon` | インベントリ用のアイコン画像(16×16 / 32×32 / 64×64)。[2Dエディター](#tools) の「アイテム用」で描けます |
| `texture` | 着たときの画像(64×64 か 128×128)。[3Dエディター](#tools) で描けます |
| `name` | 装備の名前 |
| `password` | 受け取り用のパスワード |

登録すると、着たときの見た目のプレビュー画像がDiscordに表示されます。裁断ブロックで金インゴット10個と引き換えに受け取れます。

::: tip 画像は部位ごとに2枚ずつ
`/add_clothing` は部位(帽子・服・ズボン・靴)ごとに1つずつ登録します。1つ登録するたびに、次の2枚が必要です。

| 画像 | 大きさ | 描くところ |
| --- | --- | --- |
| `texture`(着たときの画像) | 64×64 か 128×128 | [3Dエディター](#tools) |
| `icon`(インベントリに出るアイコン) | 16×16 / 32×32 / 64×64 | [2Dエディター](#tools) の「アイテム用」 |

帽子・服・ズボン・靴をそろえて作るなら、`/add_clothing` を4回使い、着たときの画像4枚とアイコン4枚を用意します。アイコンは着たときの画像とは別の絵です(3Dエディターで描いた画像はアイコンにできません)。アイコンは色の付いたピクセルが全体の1/8以上必要なので、2Dエディターの「提出前チェック」で確かめてから出すと安心です。
:::

## ツールの見た目を追加する `/add_tool` {#add_tool}

| 項目 | 内容 |
| --- | --- |
| `item_type` | ネザライトの 剣 / ツルハシ / 斧 / シャベル |
| `image` | ツールの画像 |
| `name` | 名前 |
| `password` | 受け取り用のパスワード |

鍛冶ブロックで、**見た目を変えたいネザライトのツールを右手に持った状態で** パスワードを入力すると、金インゴット32個で見た目が変わります。

## 登録したものを直す

| コマンド | 直せるもの |
| --- | --- |
| `/edit_item` | アイテム・ツールの名前と画像 |
| `/edit_clothing` | オシャレ装備の名前・アイコン・着たときの画像 |
| `/edit_block` | ブロックの名前・画像・明るさ・発光・向き |

どれも `password` に登録したときのパスワードを入れ、変えたい項目だけ指定します(空欄の項目はそのまま)。

## スキンを登録する `/skin` {#skin}

自分のマイクラのスキンを登録・更新します。詳しくは [参加方法](/guide/join#skin) を見てください。
