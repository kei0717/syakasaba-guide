# Keizonラインナップ

[K-phone](/play/kphone#keizon) の **Keizon** アプリで買えるアイテムです。

::: info
値段はゲームのデータから自動で表示しています。黄色のバッジが値段です(金インゴット・金ブロックの数)。
:::

## 乗り物

<div class="ss-item">

### 車 {#car}

<Keizon id="kei:item_car" />

4人まで乗れる車。誰も乗っていないとアイテムに戻る。

<Shots :images="['keizon_car.webp']" alt="車" />
</div>

<div class="ss-item">

### マリカ {#merio}

<Keizon id="kei:item_merio_b_dare" />

2人まで乗れるカート。ダッシュ板やジャンプ台の効果で速くなったり、空を滑空したりできる。

<Shots :images="['keizon_merio.webp']" alt="マリカ" />
</div>

<div class="ss-item">

### マリカダッシュ板 / マリカジャンプ台 {#speed-boost}

<Keizon id="kei:speed_boost_1" />
<Keizon id="kei:speed_boost_2" />

- **ダッシュ板** … マリカが上に乗ったときに加速できる。
- **ジャンプ台** … マリカが上に乗ったときに空を飛び、滑空できる。

::: warning
どちらも使い捨てです。設置したまま放置するのは禁止です。
:::

<Shots :images="['keizon_speed_boost.webp']" alt="ダッシュ板とジャンプ台" />
</div>

<div class="ss-item">

<Keizon id="kei:item_heri" />

<Shots :images="['keizon_heli.webp']" alt="ヘリコプター" />

<Keizon id="kei:item_truck" />

<Shots :images="['keizon_truck.webp']" alt="軽トラック" />
</div>

<div class="ss-item">

### ロボット {#robot}

<Keizon id="kei:item_robot" />

3人まで乗れるロボット。ジャンプでチャージして空を飛ぶ。一定時間チャージし続けると回転攻撃になる。誰も乗っていないとアイテムに戻る。

<Shots :images="['keizon_robot.webp']" alt="ロボット" />
</div>

<div class="ss-item">

### じゃんけん棒 {#sign}

<Keizon id="kei:item_sign_default" />

クリックでいろいろなデザインに変えられる棒。じゃんけんのほか、マルバツなどにも変えられ、頭の上にアイコンが表示される。チョキだけリアルなのは、1個ノリで描いたら案外うまくいったけど、ほかもやるほど気力が出なかったという主催の怠惰。

デザインは [スキルツリー](/play/skilltree) で増やせます。

<Shots :images="['keizon_sign.webp']" alt="じゃんけん棒" />
</div>

<div class="ss-item">

### メガホン {#megaphone}

<Keizon id="kei:item_megaphone" />

使っている間、声が少し遠くまで聞こえるアイテム(声量1.1倍、距離約1.5倍)。

<Shots :images="['keizon_megaphone.webp']" alt="メガホン" />
</div>
