# 工作・料理レシピ

**レシピ本** を使ってレシピを覚えると、**工作ブロック** や **料理ブロック** で、素材を使ってそのアイテムを作れるようになります。工作ブロック・料理ブロックのレシピ本は [スキルツリー](/play/skilltree) で手に入ります。

レシピ本の **手に入れ方ごと** に並べています。「素材」と「スキルツリーでの入手」の部分は、ゲームのデータから自動で表示しています。

<div class="ss-item">

### チンチロ判定機 {#chinchiro}

前に横一列で並べたサイコロ3つを、7以上のレッドストーン信号で同時に転がし、止まったら役の強さを1秒だけレッドストーン信号で出す。強い役ほど信号が強いので、コンパレーターで親と子の勝ち負けを比べられる。

| 役 | 信号の強さ |
| --- | --- |
| ピンゾロ(1・1・1) | 15 |
| ゾロ目(6〜2) | 14〜10 |
| シゴロ(4・5・6) | 9 |
| 目あり(6〜1) | 8〜3 |
| 目なし | 2 |
| ヒフミ(1・2・3) | 1 |

<div class="ss-item">

### ![](/game/textures/icon/auto_exchange.png){.hicon} 自動換金ブロック {#auto-exchange}

レッドストーン信号が入った瞬間に、**前のマス** の入れ物(チェスト・樽・ホッパーなど)の中身と、そこに落ちているアイテムを換金し、**後ろのマス** へ金インゴットを出す。レートは換金ブロックと同じ。前は置いたときに自分のほうを向く面。

- 後ろのマスが入れ物ならその中へ、入れ物がないときや入りきらない分はアイテムとして落とす。
- 置いた人がクリックすると、換金に足りない端数と、換金できないアイテムを「残す」か「送る(金と一緒に後ろへ出す)」か選べる。
- 金は口座ではなく、金インゴットそのものが出てくる。

<Recipe tag="crafting_recipe_auto_exchange" />
</div>

<div class="ss-item">

### ![](/game/textures/icon/billing.png){.hicon} 請求ブロック {#billing}

置いた人が **金額** と **一言メモ**(例: 支払うと肉を64個買えます)を決めておくと、ほかの人がクリックしたときに請求書が開く。支払うと、一瞬だけレッドストーン信号が出るので、お店の自動販売機などに使える。

- 支払いは手持ちの金インゴット・金ブロックから(金ブロックは金インゴット9個ぶん。おつりは金インゴットで返る)。
- 払われた金は置いた人の口座に入る。置いた人がログインしていなくても払える。
- 置いた人がクリックすると、金額・メモ・支払いの通知の設定と、これまでの売上が見られる。お試し(金は動かさずに信号だけ出す)もできる。

<Recipe tag="crafting_recipe_billing" />
</div>

<div class="ss-item">

### ![](/game/textures/icon/bank_io.png){.hicon} 出金/入金ブロック {#bank-io}

レッドストーン信号が入った瞬間に、置いた人の口座と金をやりとりするブロック。向いている先の1マスを相手にする(向きは置いたときに自分のほうを向く)。置いた人がクリックするとモードを切り替えられ、ランプの色が変わる。

- **入金モード** … 向いている先のマスに落ちている金インゴット・金ブロックと、そこにある入れ物の中の金を、全部口座へ入れる。
- **出金モード** … 口座から、設定した数の金インゴット/金ブロックを向いている先のマスへ出す(入れ物なら中へ)。
- 口座はワールドのデータなので、置いた人がログインしていなくても動く。残高の通知もオンにできる。

<Recipe tag="crafting_recipe_bank_io" />
</div>

### ![](/game/textures/items/item_drill_pack.png){.hicon} ドリルパック {#drill-pack}

胴体に着ける、背中のドリル。スキル「真の効率厨へ」を持っている人が着けてブロックを壊すと、背中のアームが伸びて、壊したブロックと同じ種類でつながっているものを **3×3×3** までまとめて掘る。

- スニーク中は出ない。スキルのレベルを上げると、次に掘れるまでの待ち時間が 2秒 → 1.2秒 → 0.6秒 と短くなる。
- 着けている間はネザーゲートを通れない。ゲートを使うときは外す。
