# 工作・料理レシピ

**レシピ本** を使ってレシピを覚えると、**工作ブロック** や **料理ブロック** で、素材を使ってそのアイテムを作れるようになります。工作ブロック・料理ブロックのレシピ本は [スキルツリー](/play/skilltree) で手に入ります。

::: info
「素材」と「スキルツリーでの入手」の部分は、ゲームのデータから自動で表示しています。
:::

## 遊べるブロック

<div class="ss-item">

### サイコロ {#dice}

クリックすると転がって1〜6の目が出るブロック。7以上のレッドストーン信号を入れても転がる。止まった瞬間に1秒だけ、出た目と同じ強さのレッドストーン信号を出す。

<Recipe tag="crafting_recipe_dice" />
</div>

<div class="ss-item">

### チンチロ判定機 {#chinchiro}

前に横一列で並べたサイコロ3つを、7以上のレッドストーン信号で同時に転がし、止まったら役の強さを1秒だけレッドストーン信号で出す。強い役ほど信号が強いので、コンパレーターで親と子の勝ち負けを比べられる。

| 役 | 信号の強さ |
| --- | --- |
| ピンゾロ(1・1・1) | 15 |
| ゾロ目(6〜2) | 14〜10 |
| シゴロ(4・5・6) | 9 |
| 目あり(6〜1) | 8〜3 |
| 目なし | 2 |
| ヒフミ(1・2・3) | 1 |

</div>
