# そのほかの仕様

## 珍しいモブ・ドロップ

### ![](/game/textures/items/item_rainbow_feather.png){.hicon} 虹色のオウム {#rainbow-parrot}

ジャングルに低い確率で虹色のオウムがスポーンします。虹色のオウムからは、[座れる虹色の階段ブロック](/items/recipes#ride-gaming) を作るための素材「虹色の羽」がドロップします。

<Shots :images="['rainbow_parrot.webp']" alt="虹色のオウム" />

### 非常口の被り物 {#exit}

エンドシティのチェストに低い確率で入っています。動きに合わせて動いたり、スニークで光ったりします。

<Shots :images="['omen_exit.webp']" alt="非常口の被り物" />

### ![](/game/textures/items/item_head_kei.png){.hicon} 運営のモブヘッド {#staff-head}

ごくまれに、クリーパーが運営のモブヘッドをかぶっていることがあります。そのクリーパーを倒すと手に入ります。

<Shots :images="['staff_mob_head.webp']" alt="運営のモブヘッド" />

### ![](/game/textures/items/item_kingyo_0.png){.hicon} 金魚の被り物 {#kingyo}

金インゴットで鮭を倒すとレアドロップします。プレイヤーの動きに合わせて動きます。

<Shots :images="['kingyo.webp']" alt="金魚の被り物" />

### ![](/game/textures/items/item_pien.png){.hicon} ぴえんの被り物 {#pien}

レベル50以上のプレイヤーが死んだときにドロップします。ただただ気持ち悪い。当初は全身の実装を予定していたが、参加者が減りそうなので我慢した。

## 街の設備

### 公衆電話 {#public-phone}

最初のスポーン地点の近くに設置されている公衆電話です。殴ると使えて、K-phoneを持っている人に電話をかけられます(非通知)。K-phoneを持っていない場合、遠くに行くと切断されます。

<Shots :images="['public_phone.webp']" alt="公衆電話" />

## イベント用

### ![](/game/textures/items/item_microphone.png){.hicon} マイク {#mic}

持っている人の声が、めちゃくちゃ遠くまで聞こえるようになるアイテムです。40m先でも聞こえます。

クラフトやKeizonで手に入れる方法はなく、イベントで使うときだけ運営からレンタルできます。イベントの規模が大きい場合や、町の中心から近い場合などは使えないことがあります。

<Shots :images="['mic.webp']" alt="マイク" />

## 運営にお願いするとできること {#ask-staff}

::: tip
- 支援Tシャツをなくしてしまった方への再配布
- マイクを使いたい人がいた場合のレンタル(条件があるので、詳しくは運営へ)
- 音声の加工(エコーなど)・曲を流すことの申請(条件があるので、詳しくは運営へ)
:::

## 特殊な建造物 {#special-structure}

::: details ちょっとしたウワサ(クリックで開く)
サバンナの平地で、ごくまれに特殊な建造物が生成されるらしい。

その建造物では、そこでしか買えないアイテムが販売されているらしく、1か所につき1人1つだけ購入できるとか…。
:::
