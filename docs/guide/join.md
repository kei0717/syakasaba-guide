# 参加方法

『社会性サバイバル』に参加するまでの手順です。上から順番に進めてください。

::: tip 先に参加規約を読んでください
参加する前に、必ず [参加規約](/guide/rules) を確認してください。
:::

## <span class="ss-step">1</span>Discordのニックネームを変える {#nickname}

このDiscordサーバーでの自分のニックネームを、次の形に変更します。

```
ニックネーム[マイクラID]
```

::: tip 例
`けい[badminton0717]`
:::

::: warning
`[ ]` の中のマイクラIDには、ローマ字と空白以外は使えません。
:::

## <span class="ss-step">2</span>スキンを登録する {#skin}

Discordのbot用チャンネルで、次のコマンドを実行して自分のスキン画像を登録します。

```
/skin image:(スキン画像)
```

- 画像は **PNG** 形式で、大きさは **64×64** か **64×32** だけ使えます。
- ニックネームの `[ ]` の中のマイクラIDを使って登録するので、先に手順1を済ませてください。
- スキンを変えたくなったら、もう一度同じコマンドを実行すれば上書きされます。

## <span class="ss-step">3</span>しゃかさばボイスにログインする {#voice}

下のサイトに接続し、Discordアカウントでログインします。

<a class="ss-button" href="https://kei-server.com/" target="_blank" rel="noreferrer">しゃかさばボイスを開く ↗</a>

| 端末 | おすすめのブラウザ |
| --- | --- |
| PC | Google Chrome |
| iPhone | Chrome |
| Android | Google Chrome |

## <span class="ss-step">4</span>パスワードを入力する {#password}

パスワードを入力して「送信」をクリックします。パスワードは、招待してくれた人か運営から直接聞いてください。

## <span class="ss-step">5</span>マイクを確認して通話に参加する {#mic}

右上の設定からマイクの音量などのテストを済ませたら、「参加」をクリックします。

::: danger スマホで通話に参加する方へ
スピーカーでの参加はお控えください。音の反響が大きく、周りの迷惑になることがあります。有線・無線どちらでもいいので、**必ずイヤホンを使ってください**。
:::

## <span class="ss-step">6</span>マイクラでサーバーに参加する {#server}

マイクラでサーバーを追加して参加します。サーバーのアドレスとポートは、Discordで案内しています。

## <span class="ss-step">7</span>ゲーム内でログインする {#login}

ゲームに入ったら、チャットで次のコマンドを実行してログインを済ませます。ログインするまでは動けません。

```
/login パスワード
```

コマンドの詳しい使い方は [チャットコマンド](/play/commands) を見てください。

## しゃかさばボイスがうまく動かないとき

- マイクテスト機能では、片耳しか音が返ってこないことがあります。
- 途中でイヤホンを抜き差ししたり切り替えたりすると、サイトを再読み込みしないと正しく動かないことがあります。
- Google Pixel など一部の端末では、ノイズキャンセル機能をオンにすると動かないことがあります。
- 有線・無線など、一部の環境でしか動かないことがあります。
- iPhone など一部の端末で、ログインを押しても次の画面が出ないときは、再読み込みとログインを繰り返すと直ることがあります。
- 退出ボタンを使わずに、再読み込みやキャッシュの削除などで通話から抜けた場合、数十秒間は参加し直せないことがあります。
- Cookieを許可していないと、毎回ログインし直すことになります。音量設定も毎回初期化されます。

## ホーム画面にショートカットを作る

しゃかさばボイスをすぐ開けるように、ショートカットを作っておくと便利です。

::: code-group

```txt [PC]
① デスクトップの何もないところで右クリックし、「新規作成」→「ショートカット」をクリック
② 次のリンクを貼り付けて「次へ」をクリック
   https://kei-server.com/
③ 好きな名前を付けて「完了」をクリック
```

```txt [iPhone]
① 右上の共有ボタンをタップ
② 「ホーム画面に追加」をタップ
③ 好きな名前にして「追加」をタップ

▼ いつものブラウザがChromeではない場合
リンクを開いたあと、次の手順でChromeで開き直せます。
① 共有ボタンをタップ
② 「Chromeで開く」をタップ
```

```txt [Android(Galaxyの場合)]
① 右上の「︙」をタップ
② 「ホーム画面に追加」をタップ
③ 好きな名前にして「追加」をタップ

▼ いつものブラウザがChromeではない場合
リンクを開いたあと、次の手順でChromeで開き直せます。
① 右下の「≡」をタップ
② 共有ボタンをタップ
③ 「Chrome」をタップ
```

:::
