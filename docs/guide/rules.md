# 『社会性サバイバル -season4-』参加規約

本規約は、『社会性サバイバル -season4-』にご参加いただくにあたり、厳守していただきたい事項およびご留意いただきたい事項を定めています。

本規約の[規約事項](#規約事項)に反する行為を行った参加者は、[規約違反者への対応](#規約違反者への対応)に基づいて対処します。

また、本規約の[個人の裁量で行っていただきたいこと](#個人の裁量で行っていただきたいこと)は、参加者の皆さんが平等に、そして楽しくイベントを過ごせるよう、一人ひとりに気を付けていただきたい内容です。これらの項目に反し、本イベントに悪影響を及ぼすと判断した場合は、注意させていただく場合があります。

::: tip 数字のまとめ
| 項目 | 内容 |
| --- | --- |
| 拠点を作れる範囲 | オーバーワールドの x: -300〜300 / z: -300〜300 |
| 行動できる範囲 | x: -100000〜100000 / z: -100000〜100000 |
| 高負荷な装置を作れない範囲 | x: -80〜80 / z: -80〜80 |
| モブ・エンティティの所持 | 各種 8体まで |
| 写真の設置 | 8個まで |
:::

## 規約事項

### 参加条件について

以下のいずれの条件にも当てはまらない方の参加は固く禁じます。

- Xアカウント、けい(@mcbe0717)と相互フォロー状態である方。
- 過去の『社会性サバイバル』に参加していた方。
- 招待可能条件に当てはまる方から招待を受け、その旨をDiscordの「招待・責任者」チャンネルに記載している方。

### 招待可能条件について

以下のいずれかの条件に当てはまる方は、参加条件に明記されている招待を行えます。

- Xアカウント、けい(@mcbe0717)と相互フォロー状態である方。
- 『社会性サバイバル -season2-』以前から社会性サバイバルに参加していた方。

::: info
『社会性サバイバル -season3-』を招待で参加された方は、人数過多を防止するため、招待権限がありません。あなたを招待した方に依頼するか、けいに直接ご相談ください。けいからも招待可能です。
:::

### 居住区域、行動範囲について

- 本イベントでの拠点は、オーバーワールドの **x座標: -300〜300、z座標: -300〜300** の600×600の範囲内に設けてください。
- 行動範囲は **x座標: -100000〜100000、z座標: -100000〜100000** の200000×200000の範囲内までとします。

### エンティティの所持について

各自で所持・飼育できるモブ、エンティティの数は **各種8体まで** とします。数名で共同生活している場合も、判断が難しいため各種8体までとします。

→ 関連: [エンティティに当てはまるもの](/guide/faq#エンティティ)

### 写真の設置について

各自で設置できる写真の数は **8個まで** とします。

### 回路について

- 常時稼働しているもの(クロック回路など)は禁止とします(条件によって一時的に起動するものは許可)。
- 高負荷な装置は、**x座標: -80〜80、z座標: -80〜80** の範囲内での作成を禁止し、人がいなくなる時には稼働を停止してください。

→ 関連: [ホッパー付きトロッコなどが動き続ける状態](/guide/faq#ホッパー付きトロッコ)

### トラップについて

- 常時稼働しているトラップは禁止とします。人が感圧板を踏んでいる間のみモブが湧く設計のみ許可します。
- 放置などでモブが湧きすぎる可能性のある設計は禁止とします。
- 例外として、物価の上昇を防ぐため、ピグリンなど金を大量に得ることのできるトラップ、およびあまりに高負荷になるトラップの使用を禁止します。

→ 関連: [アレイ、シルバーフィッシュを使った経験値トラップ](/guide/faq#経験値トラップ)

### エンダードラゴン討伐について

個人での初回討伐は禁止とします(イベント開始から1週間〜10日ほど経過後、参加者全員で行う予定です)。また、討伐までエンドに入る行為も禁止とします。

### ウィザー討伐について

エンド以外での討伐は禁止とします(地形破壊の恐れがあるため)。

### ロールプレイ、商売について

- ロールプレイや商売は許可しますが、一部の他の参加者を拘束、強制、不快にするようなロールプレイ、商売は禁止とします(例: 警察、泥棒)。
- ロールプレイや商売を行ったことによるいかなるトラブル、損害についても、主催者は一切の責任を負いません。

### 各種追加ブロックについて

- 『座れる階段』、『座れる座布団』を椅子以外の目的で使用すること(隠し扉など)を禁止します。
- 『防音ブロック』を防音目的以外での使用、および表面に見えない状態での設置を禁止します。

### 他人を不快にさせる行為について

他人を不快にさせる行為を固く禁じます。

### バグの不正利用について

バグを意図的に利用し、利益を得ようとする行為を固く禁じます。

→ 関連: [ブロック更新を高速で行う装置](/guide/faq#ブロック更新装置)

### 外部ツールの利用について

連打ツールやマクロなどのMinecraft内に影響を与える外部ツールの利用を禁じます。

### サーバー負荷について

サーバーへ意図的に負荷をかける行為を禁止します。

例: 意味なく世界生成を広げる、必要のないモブに名札をつけデスポーンしなくする、使い道のない手紙を大量に作成する、必要のない高負荷なブロックを大量に設置する など。

### 写真、動画撮影およびSNSへのアップロードについて

- 写真、動画撮影はすべての場合において許可します。
- それらをSNSにアップロードする行為についても許可しますが、映っている人のプライベート、自尊心等を侵害する、不快にする内容のアップロードは禁止とします。
- これらによって起こったいかなるトラブル、損害についても、主催者は一切の責任を負いません。

### 配信活動について

- 配信行為は許可しますが、必ず配信のタイトル、概要欄など見える場所に『社会性サバイバル』という言葉を使用してください。
- 必ず [K-phoneアプリ](/play/kphone#live) と [チャットコマンド](/play/commands#live) に記載されているLiveモードをONにして行ってください。
- 通話機能を使用する際は、必ず配信している旨を伝えるようにしてください(待機VCなどMinecraft外での音声を入れることは禁止とします)。
- 配信を行ったことによるいかなるトラブル、損害についても、主催者は一切の責任を負いません。

### 常識を逸脱した行為について

上記項目に記載がない場合でも、常識を逸脱した行為などで、本イベントに悪影響を及ぼすと判断した場合、[規約違反者への対応](#規約違反者への対応)に基づいた対応をする場合があります。

### 規約変更・バランス調整について

前触れなく、本イベント中に規約内容やゲーム内のバランスに修正、調整が入る場合があります。

### サーバーによるデータのロールバックについて

本イベントはサーバーで行うため、サーバーを再起動した際などにデータのロールバックが発生する場合がありますが、それによって生じたいかなる損害も、主催者は一切の責任を負いません。

### サーバー内での放置行為について

サーバー内で、満員・混雑時の放置を禁止します。

### サーバー参加中の配信視聴について

サーバー参加中に他の人の社会性サバイバルの配信を視聴することを禁止します(新たなコミュニケーション手段となるため)。

### 通話参加中の音源の加工・編集について

通話に送る音源を加工したり、自分の肉声や楽器の音以外の音源、または他の通話音を入れることを禁止します。ただし、ノイズキャンセルを目的とするツールの使用は許可します。やむを得ない事情がある場合は、例外として運営の了承を得た時のみ許可します。

### Discordのボイスチャンネルについて

- 「VC_緊急用」の使用は、非常時以外禁止とします。
- 「VC_1」から「VC_40」の使用は、画面共有、ビデオ通話目的以外での使用を禁止し、近くの人のみ視聴できるものとします。

### イベント開催・施設営業情報チャンネルについて

Discordの「イベント開催・施設営業情報」チャンネルは、イベント開催情報、施設の営業時間などのお知らせ以外での使用を禁止します。

### プレイヤー以外のエンティティに装着禁止なアイテムについて

以下のアイテムをプレイヤー以外に装着し、そのままの状態にすることを禁止します。

- 非常口の被り物
- デジタルコンパス
- ぴえんの被り物
- 公衆電話の受話器

## 規約違反者への対応

規約違反者については、以下の項目から本イベント運営の判断によって対応を行います。

- 厳重注意
- 不正に得た利益の押収
- 一定期間の参加禁止
- 永久的な参加禁止

また、参加条件の3つ目「誰かからの招待によって参加したもの」については、上記の罰則を招待した責任者にも行う場合があります。

## 個人の裁量で行っていただきたいこと

- 全体チャット(使い方は [チャットコマンド](/play/commands#全体チャット) 参照)にて細かいコミュニケーションをとることは極力避けてください。サバイバルの序盤、電話を所持していない人が、共同生活をしている人と合流するためや、緊急時の連絡に使うものとして実装しています。
- 物々交換を禁止するわけではありませんが、極力通貨として金を使用してください。
- SNSへの投稿や配信などをするときは「#社会性サバイバルseason4」を極力つけてください。
- 本イベントは言語設定を日本語にすることを前提で開発しています。

## その他注意事項

バニラの仕様のうち、以下の要素に変更が入っています。ご了承ください。

- プレイヤーの肩にオウムが乗るという仕様が動作しなくなっています。頭の上に好きなテキストを乗せるために仕様を消さざるを得なかったためです。
- ウィンドチャージが時間で消失するように変更が入っています。空に向かって投げると永遠に消えないため、このような変更を加えています。
- 居住区域内でファントムが湧かないようになっています。

## 免責事項

参加者が本イベントによって生じたいかなるトラブル、損害についても、本イベント運営は一切の責任を負いません。
